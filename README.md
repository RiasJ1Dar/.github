# .github

Типові community-файли для всіх репозиторіїв.

| Файл | Що робить |
|---|---|
| [CLA.md](CLA.md) | **угода контриб'ютора**: ви лишаєтесь автором свого коду, проєкт отримує право випускати його під різними умовами |
| [.github/CONTRIBUTING.md](.github/CONTRIBUTING.md) | як надіслати внесок |
| [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md) | шаблон pull request із позначкою прийняття угоди |
| `.github/FUNDING.yml` | кнопка **Sponsor** |

Кожен із них застосовується до репозиторію, у якому немає власного такого
файлу. Репозиторій зі своїм `CONTRIBUTING` або шаблоном PR використовує свій.
